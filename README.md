# Ecos de Vidrio

RPG 3D por turnos (estilo JRPG) para Android. Historia y personajes originales.

## Cómo se juega
- **Extraer:** roba magias (Fuego, Hielo, Rayo, Piedra, Cura) a los enemigos y guárdalas.
- **Vínculos:** en el Menú, vincula esas magias a Vida, Fuerza, Defensa, Magia o Velocidad. Más cantidad = más bono.
- **Ecos:** criaturas que invocas en combate (Ignar, Volt, Nivalis, Terragon). Cada Eco desbloquea vínculos.
- **Arte final:** cuando un personaje tiene poca vida, aparece su ataque especial.
- Los cristales azules curan y guardan la partida.

## Compilar el APK en GitHub
1. Crea un repositorio vacío y sube todo este contenido (incluida la carpeta `.github`).
2. Ve a **Actions** → "Compilar APK" y espera el ✅.
3. Descarga **Ecos-de-Vidrio-apk** en "Artifacts".
